Canton Names

Readable names for Canton party IDs

The Problem

On Canton, sending value still depends on long opaque party IDs that are easy to mistype and hard to trust.

One wrong character → transfer fails or wrong recipient

The Solution

Canton Names turns party IDs into readable names like alice.unverified.cns

Drop-in recipient field that:

  • Resolves the name to the right party
  • Warns before sending if missing, expired, or unverified
Recipient
alice::1220a3f9b8c4d5e6f7a8b9c0d1e2...
alice.unverified.cns ✓ Resolved
⚠ Expired — name no longer valid
✕ Not found — check spelling
ⓘ Unverified — not identity-checked
