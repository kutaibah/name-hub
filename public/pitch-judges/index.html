Canton Names

Safe recipient resolution for Canton apps

A drop-in component that resolves names to party IDs and blocks risky transfers before they happen.

The Problem

On Canton, sending value depends on long, opaque party IDs:

alice::1220a3f9b8c4d5e6f7a8b9c0d1e2f3a4b5c6d7e8f9a0b1c2d3e4f5a6

One wrong character — transfer fails or reaches the wrong party. No way to verify before sending.

The Solution

Canton Names is a safe recipient resolution component

Drop-in CnsRecipientInput

One React component with resolution, validation, and confirmation flows.

Transfer safety

  • Blocks missing/expired names
  • Confirms unverified/changed
  • Never sends to the wrong party
